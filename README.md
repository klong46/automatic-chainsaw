# automatic-chainsaw

Automatic Chainsaw is a random placeholder name for game I could possibly make if I decide it's worth staring at a computer in my free time. My idea has nothing to do with chainsaws.

I spend a lot of time using AI at work for software development and it's pretty easy to see how useful it is for writing good code, fast. Enterprise software also does not require a ton of creativity to develop and most of what I spend time thinking about is architecture and design.

However, when it comes to game development, effective use of AI tools becomes a bit trickier. It's tempting to think that any cool idea you have can be spun up into a fully functional game in a few hours with a few well-written prompts. Suddenly, the barrier to making a game idea reality is smaller than ever.

The problem is that there is still a big difference between vibing out a neat game demo and shipping a polished game that's actually fun.
